# Europe market

Use this overlay for cross-border searches rather than a single country. Before searching, resolve:

- included countries or regions;
- whether the UK and Switzerland are included;
- on-site, hybrid, and remote preferences;
- current work authorization and whether sponsorship is required;
- working languages and minimum acceptable language requirements;
- relocation limits and salary currency.

Search results must retain country, city/remote status, posting language, stated language requirements, work-authorization or sponsorship evidence, contract type, and salary currency when stated. Never infer visa sponsorship from an English-language posting.
