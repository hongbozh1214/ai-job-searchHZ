# Europe profile setup

Keep the tracked template and personal data separate:

- `markets/europe/profile/preferences.md` is a public template and must remain free of personal data.
- `documents/europe/profile/preferences.md` is the user's gitignored personal copy.

If the personal file is missing, create `documents/europe/profile/` and copy the tracked template into it. Then ask only for unresolved Europe-specific preferences and write answers to the personal copy. Never edit the tracked template during user setup.

The shared candidate evidence under `.claude/skills/job-application-assistant/` remains the source of truth for identity, experience, education, skills, and achievements. Europe preferences may add search constraints but may not contradict those facts. Keep unknown values explicit instead of guessing.
