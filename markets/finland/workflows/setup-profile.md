# Finland profile setup

Keep the tracked template and personal data separate:

- `markets/finland/profile/preferences.md` is a public template and must remain free of personal data.
- `documents/finland/profile/preferences.md` is the user's gitignored personal copy.

If the personal file is missing, create `documents/finland/profile/` and copy the tracked template into it. Then ask only for unresolved Finland-specific preferences and write answers to the personal copy. Never edit the tracked template during user setup.

The shared candidate evidence under `documents/profile/` remains the source of
truth for identity, experience, education, skills, and achievements. The
corresponding `.claude/skills/job-application-assistant/` files are tracked
methodology/templates only. Finland preferences may add search constraints but may
not contradict the local facts. Keep unknown values explicit instead of guessing.
